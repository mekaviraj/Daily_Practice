# 4. Autonomous Reliability Intelligence Agent

### Problem

Food delivery systems process millions of events:

* Orders
* Payments
* Deliveries
* Refunds

Failures cause:

* Duplicate orders
* Lost orders
* Delayed deliveries

Current dashboards only show issues after they occur.

### Solution

Create an autonomous AI operations platform.

### Agent 1

Monitoring Agent

Detects:

* Latency spikes
* Message loss
* Duplicate events

### Agent 2

Investigation Agent

Analyzes:

* Kafka logs
* Spark metrics
* Service traces

### Agent 3

Knowledge Agent

RAG over:

* Historical incidents
* Runbooks
* Architecture docs

### Agent 4

Prediction Agent

Predicts:

* Service degradation
* Failure probability
* Future bottlenecks

### Agent 5

Recommendation Agent

Suggests:

* Increase partitions
* Restart consumer
* Scale service
* Retry workflows

### Advanced Features

Fine-tune a small model on:

* Incident reports
* Reliability tickets
* Postmortems

### Tech Stack

* Kafka
* Spark Streaming
* LangGraph
* FAISS
* Llama
* FastAPI
* PostgreSQL
* Grafana

### Why This Stands Out

Most students build:

> "Chat with PDF"

This project looks like something a real AI engineering team would build inside a company.

For a Lloyds AI Research Intern interview, Project #4 is the strongest by far, Project #2 is second, Project #3 is third, and Project #1 gives you the ML fundamentals to discuss confidently.
